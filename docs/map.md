# Map

Geographic layer for the knowledge base.

**Data file (Kepler.gl ready):** [`maps/covid-origins-layered-v7.csv`](https://github.com/BnBCleaners/truth-map/blob/main/maps/covid-origins-layered-v7.csv) in the repository.

### How to view
1. Open [kepler.gl/demo](https://kepler.gl/demo)
2. Upload the CSV from the repo
3. Color by `layer_group`, size as needed, enable the time filter on the `date` field

Layers include COVID Core sites, high-containment laboratories, and related nodes.
