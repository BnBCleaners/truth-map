# How to contribute

Public contributions keep the instrument alive. They must meet the evidence standards.

## Preferred channel: GitHub Issues

Open a new Issue on the **Truth-Map** repository:

**[Open an Issue →](https://github.com/Truth-Map/truth-map/issues/new/choose)**

Suggested issue types:

| Type | Use for |
|------|---------|
| **New Evidence** | Primary-source evidence for an existing Claim or Case |
| **New Claim proposal** | A new scored truth proposition |
| **New Case proposal** | A new event reconstruction |
| **Correction** | Fix an error in an existing page |
| **Process question** | Ask about the rules or workflow |

Each submission should include:

1. **Exact target** (Claim ID, Case name, or file path)
2. **Primary source(s)** (URL, document title, date, archive link if possible)
3. **Short plain-English summary** of what the source shows
4. **Suggested label** (Confirmed / Supported / Contested / Unsupported / False)

## Alternative: Pull Request

Fork the repository, make a focused change that follows the existing card style, and open a PR. Keep it small and reviewable. Source-free or speculative PRs will be closed.

## Gatekeeping (non-negotiable)

- Primary sources first
- Clear labels on every claim
- Evidence for **and** against
- No doxxing, no illegal material, no speculation presented as fact

Submissions are reviewed against these rules. Accepted material is integrated into the official files. Rejected material is closed with a short public explanation.

You and the maintainers remain the quality gatekeepers. No one writes directly into the official record without review.
