# How to contribute

Public contributions keep the instrument alive. They must meet the evidence standards.

## Preferred channel: GitHub Issues

Open a new Issue and choose one of the templates:

- **New Evidence** — primary-source evidence for an existing Claim or Case
- **New Claim proposal** — a new scored truth proposition
- **New Case proposal** — a new event reconstruction
- **Correction** — fix an error in an existing file
- **Process question** — ask about the rules or workflow

Each template requires:

1. Exact target (Claim / Case / file)
2. Primary source(s)
3. Short plain-English summary of what the source shows
4. Suggested confidence label

## Alternative: Pull Request

Fork the repository, make a focused change that follows the card templates, and open a PR. Keep it small and reviewable. Source-free or speculative PRs will be closed.

## Gatekeeping

Submissions are reviewed against the core rules. Accepted material is integrated into the official files. Rejected material is closed with a short public explanation.

You and Grok remain the quality gatekeepers. No one writes directly into the official record without review.
