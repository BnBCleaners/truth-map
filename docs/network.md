# Network Graph

Relationship data for the early-origins cluster and key institutions.

**Files in the repository:**
- [`graphs/covid-network-v2-nodes.csv`](https://github.com/BnBCleaners/truth-map/blob/main/graphs/covid-network-v2-nodes.csv)
- [`graphs/covid-network-v2-edges.csv`](https://github.com/BnBCleaners/truth-map/blob/main/graphs/covid-network-v2-edges.csv)

### What the edges capture
- Funding relationships (NIH → EcoHealth → WIV)
- 31 Jan / 1 Feb 2020 call participation (from Fauci diary)
- Proximal Origin co-authorship
- Diary documentation links
- Lancet letter organization

Load the CSVs into Cosmograph, Gephi, or any graph tool that accepts node/edge tables.
