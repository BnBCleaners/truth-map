# Pilgrims Society

<span class="badge badge-contested">Elite Society</span>

**What it is:** Anglo-American dining and networking society (founded early 20th century) promoting closer UK–US relations.

**Documented facts:** Membership historically included senior political, diplomatic, finance, and media figures on both sides of the Atlantic. Overlaps with CFR and related Atlanticist networks.

**Contested framings:** Secret-government claims are Contested. Elite networking is documented; command authority is not.

**Cross-links:** CFR · Chatham House · Atlanticist set
