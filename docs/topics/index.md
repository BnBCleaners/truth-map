# Topics

Complex public subjects that contain multiple distinct factual angles.  
A Topic itself does **not** receive an overall score. The real work lives in the scored Angles underneath it.

### How Topics work

1. The Topic is the public subject people argue about.
2. Under it sit individual **Angles** — each a tight, scoreable factual proposition.
3. Every Angle still follows the core rules: primary sources first, clear label, evidence for and against.
4. This structure exists so the sifting stays visible instead of being collapsed into one misleading overall score.
