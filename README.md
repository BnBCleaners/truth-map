# Truth Map

**A neutral, evidence-based, open-source research instrument**  
Mapping people, organizations, events, claims, connections, and financial flows over time.

**Goal**  
Help ordinary people see what is solidly known, what is still contested, and what is unsupported — with the evidence shown either way.

This is not a conspiracy archive.  
It is a structured research tool designed to keep the record honest, searchable, and accountable.

**Live site:** https://bnbcleaners.github.io/truth-map/

---

## Core Rules (non-negotiable)

1. **Primary sources first** — court documents, official records, financial filings, contemporaneous notes, verified data.
2. **Clear labels on every claim**
   - **Confirmed** — strong primary evidence
   - **Supported** — good evidence, not yet complete
   - **Contested** — serious disagreement exists
   - **Unsupported / Misleading** — weak, false, or presented in a way that misleads (and we show why)
3. Always show evidence **for and against**.
4. Keep language as clear and simple as possible.
5. No doxxing, no illegal material, no pure speculation presented as fact.
6. Public contributions are welcome. They are reviewed against these standards before becoming part of the official record.

---

## How the knowledge base grows

- **Claim / Case-driven**: We expand people, organizations, and facilities only when an active Claim or Case requires them.
- Supporting data is built as needed, not collected for its own sake.
- Deduction and gap-bridging are allowed, but must be clearly labeled as *hypothesis / worth researching* — never asserted as fact.

See `ARCHITECTURE.md` for the full data model, folder structure, and research depth levels.

## How to contribute

See **[CONTRIBUTING.md](CONTRIBUTING.md)** for the exact process.

Short version:
- Open an Issue using one of the templates (New Claim, New Evidence, Correction, New Case).
- Or submit a Pull Request that follows the evidence standards.
- Low-quality, speculative, or source-free submissions will be closed with an explanation.
